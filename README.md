# 💸 NabApps - Modern Financial Management

![Vite](https://img.shields.io/badge/vite-%23646CFF.svg?style=for-the-badge&logo=vite&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=for-the-badge&logo=supabase&logoColor=white)

**NabApps** adalah aplikasi manajemen keuangan (Buku Kas) cerdas dan modern yang dirancang untuk membantu Anda mencatat, merencanakan, dan melacak setiap pengeluaran maupun pemasukan dengan sangat mudah.

## ✨ Keunggulan & Fitur Utama

- 🎨 **Desain UI Premium (Glassmorphism):** Antarmuka yang cerah, modern, dan dilengkapi dengan efek *frosted glass* serta animasi super mulus untuk memberikan pengalaman pengguna (*UX*) tingkat tinggi.
- 🤖 **Pemindai Struk Cerdas (AI Scanner):** Terintegrasi dengan **Google Gemini AI**. Cukup unggah atau foto struk belanja Anda, dan AI akan otomatis mengekstrak nominal, nama *merchant*, serta deskripsi belanjaan ke dalam form!
- 👥 **Buku Kas Kolaborasi (Multi-User):** Mendukung kolaborasi antar pengguna! Anda bisa menggabungkan buku kas dengan rekan/pasangan dan sistem akan menghitung serta melacak "Saldo Masing-Masing" secara otomatis di *Dashboard*.
- 📊 **Dashboard Analitik Dinamis:** Tata letak kartu responsif (*auto-fit grid*). Dilengkapi *Hero Card* mewah untuk Saldo Utama dan rincian terpisah (Tabungan, Pemasukan, Pengeluaran) yang beradaptasi dengan sempurna di layar HP maupun Desktop.
- 🌳 **Manajemen Kategori Berlapis:** Mendukung *Main Category* dan *Sub-Category* dengan tampilan struktur pohon (*Tree View*) yang sangat interaktif dan terorganisir.
- 🎯 **Sistem Budgeting Cerdas:** Alokasikan uang Anda ke pos-pos anggaran bulanan agar keuangan lebih terencana dan tidak *over-budget*.
- ⚡ **Cepat & Real-time:** Dibangun dengan performa tinggi menggunakan **Vue 3 + Vite** (Frontend) dan disokong oleh **Supabase** (Backend/Database) untuk sinkronisasi data yang cepat.

## 🚀 Instalasi & Menjalankan Project

1. Pastikan Anda telah menginstal Node.js di komputer Anda.
2. *Clone* repositori ini.
3. Masuk ke direktori project dan jalankan perintah instalasi dependensi:
   ```bash
   npm install
   ```
4. Tambahkan konfigurasi `.env` untuk Supabase & Gemini AI (sesuai kebutuhan *environment* Anda).
5. Jalankan server lokal:
   ```bash
   npm run dev
   ```
6. Buka `http://localhost:5173` di *browser* Anda.
